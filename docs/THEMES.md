# Lighthouse themes

A theme is a folder holding a `theme.json` and (optionally) background images.

- **Bundled themes** live in `app/src/main/assets/themes/<id>/`.
- **Your own themes:** put the folder in **`Lighthouse/themes/<id>/`** on any storage volume (internal or SD card). Lighthouse picks it up the next time it comes to the foreground. A user theme with the same `id` as a bundled one overrides it.

Choose a theme in **Settings → Appearance**.

## `theme.json`

```json
{
  "id": "synthwave",
  "name": "Synthwave",
  "author": "Lighthouse",
  "version": 1,
  "colors": {
    "background": "#0B0221",
    "surface": "#1A0F2E",
    "accent": "#FF2E97",
    "text": "#FFFFFF",
    "textMuted": "#C9B8E8",
    "focus": "#FFFFFF"
  },
  "cover": { "cornerRadius": 10, "focusScale": 1.06 },
  "scrim": 0.25,
  "backgrounds": {
    "default": "home.webp",
    "home": "home.webp",
    "platform:android": "android.webp",
    "platform:switch": "switch.webp",
    "platform:ps2": "ps2.webp",
    "platform:gba": "gba.webp"
  }
}
```

| Field | Meaning |
|---|---|
| `colors.background` | Base colour: the bottom of the tinted gradient when a view has no image, and pop-up backdrops. |
| `colors.surface` | Panels and dialogs (quick settings, Settings, game options). |
| `colors.accent` | Progress bars, the volume slider, selected-theme marker. |
| `colors.text` / `textMuted` | Main and secondary text. |
| `colors.focus` | The ring around the focused cover. |
| `cover.cornerRadius` | Cover corner radius in dp (0–40). |
| `cover.focusScale` | How much the focused cover grows (1.0–1.2). |
| `scrim` | 0–0.9: black overlay on backgrounds, for readability. |
| `backgrounds` | View key → image file in the theme folder. Any key can be left out; `default` is used for views without their own. |

**View keys:** `home`, and `platform:<id>` for each tab. Platform ids are `android`, `switch`, `ps2`, `gba`, `gbc`, `n64`, `droiddeck` and `gamenative`.

All fields except `id` and `colors` are optional. Colours are `#RRGGBB` or `#AARRGGBB`.

## Background images
- **Size:** 1920×1080 (16:9). Images are cropped to fill the screen.
- **Format:** WebP or PNG. WebP at quality ~80 keeps a full theme around 0.7 MB.
- **Readability:** keep busy detail away from the **top-left** (tab bar, title, focused cover) and the **bottom** (metadata, button hints). Put interest top-right and in the lower-right "floor".

The bundled backgrounds are generated by `tools/themegen/gen.py`. It writes SVGs; render them with `rsvg-convert`, then convert them with `magick … -quality 82 x.webp`.
